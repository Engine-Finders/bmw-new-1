Our Approach to Corrections

We are accountable to the data, not to the suppliers. If we publish an error, we correct it openly and log it permanently.

Every number on this site carries a data tag ([EM-VERIFIED], [EM-QUOTE], [PATTERN DATA], or [THIRD-PARTY]), but tags do not make us immune to error. We rely on multiple sources — enquiry data, specialist interviews, third-party market data — and sometimes those sources are updated, corrected, or found to be inconsistent.

When that happens, we update the affected page, note the correction in this log, and, where relevant, add a correction notice directly on the page itself. Our editorial standards and data verification pages set out the broader framework.

The Types of Corrections We Make

Not all corrections are the same. We distinguish between three categories.

📊 Data Corrections

Changes to quoted figures — costs, volumes, percentages, mileage ranges — where the underlying data source has been updated or a transposition error has been identified.

🔧 Technical Clarifications

Refinements to technical descriptions — failure mechanisms, engine codes, fitment details — where specialist feedback or new evidence shows the original wording was incomplete or misleading.

📝 Editorial Updates

Changes to language, clarity, or framing that do not affect factual substance but improve accuracy or reduce ambiguity — e.g., replacing "all N47 engines" with "N47D20C and N47D20A variants".

Our editorial standards set out the bar for each type.

Our Correction Process

How we identify, verify, and publish corrections — step by step.

  1. Identification — Error identified via internal review, reader report, specialist feedback, or data-source update.
  2. Verification — We cross-check against the primary source (proprietary data file, specialist interview notes, manufacturer TSB, etc.).
  3. Correction — The affected page is updated. If the change is substantive, a correction notice is added to the page.
  4. Logging — The correction is entered into this log with date, page, original text, corrected text, and rationale.
  5. Notification — For significant corrections, we alert subscribers and update the editorial changelog.

Full details on how we handle corrections are on our editorial standards page.

Report an Error

If you spot an error on this site, we want to know.

We take accuracy seriously. If you find a factual error, a broken link, or something that seems outdated, please let us know. We will investigate, correct if necessary, and log the change.

To report an error, please use our contact page and include:

  • The page URL where the error appears
  • A clear description of what is incorrect
  • Any supporting evidence (e.g., official spec sheet, TSB, or your own specialist knowledge)

We aim to acknowledge all error reports within 48 hours and, where substantiated, issue a correction within 5 working days. Our editorial standards and specialist vetting pages set out our commitment to accuracy.

Frequently Asked Questions

Do you correct errors without telling anyone?

No. All substantive corrections are logged on this page, with dates, original text, corrected text, and rationale. Minor typographical or grammatical fixes are not logged but are still corrected.

How do you decide what counts as a "substantive" correction?

Any correction that affects a quoted figure, a technical specification, a failure pattern, or a recommendation is logged. Changes to wording that do not affect factual substance are not logged but are still made.

Can I request a correction if I disagree with your interpretation?

Yes. We welcome feedback. If you believe our interpretation is incorrect, please use the contact page with supporting evidence. If we agree, we will correct and log it. If we disagree, we will explain why.

Do you correct third-party data?

We use third-party data (e.g., Auto Trader valuations, manufacturer TSBs) with explicit sourcing. Where that data is updated or corrected by the source, we update our pages accordingly and log the change.

What about corrections to case studies or data reports?

Corrections to case studies or data reports are treated with the same rigour. They are logged here, and any affected chart or table is updated and annotated.
