U0100 means the engine control module (ECM) has lost communication with another control module on the vehicle's CAN bus network. In most BMWs, this is a wiring, connector, or battery issue — not an engine failure. A communication reset or wiring repair typically costs £80–£300 [PATTERN DATA], while a failed module can cost £500–£1,200.

  • Most common real cause: low battery voltage or poor connection — often resolved by a battery reset or charging
  • Worst case: failed module or ECU requiring replacement and coding
  • Often accompanied by multiple other fault codes and symptoms like limp mode
  • Frequently appears with P0562 (low voltage) — the combination confirms a power supply issue

Do not let anyone sell you a new ECU before the battery, wiring, and connectors have been checked. Full diagnostic order below.

What U0100 Actually Means

In a BMW, the ECM (Engine Control Module) communicates with other modules — such as the transmission, ABS, and instrument cluster — over a network called the CAN bus (Controller Area Network). U0100 is a generic OBD-II code that means the ECM has lost communication with another module. The code does not identify which module is missing — it simply indicates that the network is broken somewhere. This is almost always an electrical or network issue, not a mechanical engine fault. The most common cause is low battery voltage, which can prevent modules from communicating properly. Other causes include corroded wiring, a blown fuse, a faulty module, or a software glitch. On BMWs, this code appears across N47, B47, N57 and B57 engines, as well as petrol variants. The diagnostic approach is the same regardless of engine: start with the cheapest and most common causes first.

Symptoms You'll Notice Alongside It

  • Engine management light illuminated
  • Transmission fault warning or other warning lights
  • Noticeable power loss or limp mode — the car may limit performance
  • Intermittent stalling or hesitation
  • Instrument cluster gauges may behave erratically
  • In some cases, no drivability issues — just the light on the dash

Diagnostic Order — Cheapest First

1

Check battery voltage and connections

Low voltage is the most common cause. A battery test and reset often resolve U0100. Clean any corroded terminals.

2

Inspect fuses

Check all fuses related to the ECM and CAN bus. A blown fuse is a cheap and easy fix.

3

Check the ECM connector and wiring

Inspect the main ECU connector for corrosion, bent pins, or damage. Check the wiring harness for chafing.

4

Check other module connectors

If the code points to a specific module (e.g., transmission), check that module's wiring and connector.

5

Test modules / consider replacement

If all wiring and power supply checks are clear, a module may need replacement and coding.

Can You Still Drive It?

Yes — but with caution. U0100 on a BMW is not an engine mechanical fault. If the car is running and not in limp mode, you can drive it to a garage. However, if the car has entered limp mode or is stalling, you should avoid motorway driving and get it checked immediately. Prolonged driving with a communication fault can lead to further issues, as modules may not be sharing data correctly. On B47 and B57 engines, the ECU is well-protected, but on N57 it's worth checking the battery first. Get it diagnosed promptly — the cost gap between a wiring repair and a module replacement is large.

Related Fault Codes

U0100 rarely appears alone. Which codes accompany it materially changes the diagnosis.

P0562 — System Voltage Low

If this appears with U0100, the battery is almost certainly the issue.

U0101 — Lost Communication with TCM

Points specifically to a transmission module communication issue.

U0106 — Lost Communication with ECM

Similar to U0100 but from the perspective of another module.

P0700 — Transmission Control System

Often accompanies U0100 when the transmission module is affected.

Frequently Asked Questions

Can I drive with U0100 on a BMW?

Yes, for short journeys — but avoid motorway driving if the car is in limp mode. Prolonged driving with a communication fault can lead to further issues.

Does U0100 always mean the ECU needs replacing?

No. In most cases, the cause is a low battery, a poor connection, or a blown fuse — all of which are cheap to fix. ECU replacement is a last resort.

How much does it cost to fix U0100 on a BMW?

It ranges from £80–£200 for a battery reset, £100–£400 for wiring repairs, and up to £500–£1,200 for a module replacement.

Will clearing the code fix it?

Only temporarily. The code will return if the underlying fault (battery, wiring, module) is not addressed. Clearing it also erases freeze-frame data that a specialist would use to pinpoint the cause.
