BMW engine codes follow a consistent pattern: a letter (family) + two digits (displacement) + optional suffix. The letter indicates the engine family: M (older), N (modern), B (latest modular), S (high-performance).

  • Example: N47D20C — N series, 4-cylinder, 2.0L diesel, variant C.
  • How to find yours: Engine stamp on block, VIN (positions 4–7), or build sheet under bonnet.
  • Use our full fitment guide to see which models use each engine.
  • For detailed specs, visit the dedicated Engine Knowledge Centre for each code (e.g., /engine/n47).

Family Key: What the First Letter Means

BMW engine codes always start with a letter that defines the engine family and era.

  • M — Classic era (1980s–2000s). Examples: M20, M30, M40, M42, M43, M44, M47, M57. Mostly iron-block or early aluminium.
  • N — Modern era (2000s–2015). Examples: N47, N57, N20, N55, N63. Aluminium blocks, direct injection, turbocharging.
  • B — Modular era (2014+). Examples: B37, B38, B47, B48, B57, B58. Common architecture across cylinder counts, improved efficiency.
  • S — High-performance (M models). Derived from base engines with stronger internals, upgraded turbos, and bespoke tuning. Examples: S55, S63.
  • W — Rare/historic (e.g., W10, W11). Only used for some 1980s engines.

The digits after the letter indicate the approximate displacement in litres (e.g., N47 = 2.0L, B58 = 3.0L). The final letter(s) denote variant and generation.

Variant Suffixes & What They Mean

The suffix after the displacement code provides additional detail:

  • D — Diesel (e.g., N47D20 → 2.0L diesel).
  • B — Petrol (e.g., B58B30 → 3.0L petrol).
  • P — Usually hybrid or specific variant (rare).
  • Additional numbers — Variant code (e.g., N47D20C indicates a specific version with different power output or emission standard).

Sometimes the full code includes a letter for the generation (e.g., N47D20C vs N47D20A). The full variant can be identified from the engine stamp or VIN. For a detailed breakdown, refer to the engine number location guide.

Real-World Caveats

Not all BMW engines follow the exact pattern. Some older engines (e.g., M20) use a different numbering system. Additionally, engine codes can sometimes be confused with chassis codes. Always cross-check the engine number on the block itself, as this is the definitive identifier.

For cars after 2010, the engine code is also embedded in the VIN (positions 4–7). The VIN decoder tool can help extract this automatically. If you're still unsure, consult our engine code guide for model-specific fitment.

Common Mistakes When Identifying an Engine

  • Confusing the engine code with the chassis code. E.g., "E90" is the chassis, not the engine. The engine is something like N47.
  • Assuming all N47 engines are identical. There are numerous variants (N47D20A, N47D20B, N47D20C) with different power and reliability profiles. Always check the full suffix.
  • Relying on the badge on the boot. The badge (e.g., 320d) does not always reflect the exact engine code, especially on facelifted models.
  • Using aftermarket parts catalogues without verification. Many aftermarket listings use generic codes; always confirm with the engine stamp or VIN.
  • Ignoring the year of manufacture. BMW often replaced engines mid-generation. For example, F30 320d pre-2014 used N47, post-2014 used B47. Use the build date to narrow down the correct family.

How to Verify Your Engine Code on the Vehicle

The most reliable method is to read the engine number stamped on the engine block. This is usually located on the front left side (when viewed from the driver's seat) or on the top of the block near the intake manifold. The full engine number includes the code, variant, and unique serial number. You can also find the code on the build sheet (usually under the bonnet or inside the driver's door jamb) or decode the VIN using online tools (we recommend our VIN decoder). For older models, the engine code may be on a sticker on the timing cover.

If you have the VIN, the 4th–7th digits often indicate the engine type. For example, a VIN starting with WBA7A... might decode to a B58 engine. However, this can be ambiguous; the engine stamp is definitive.
